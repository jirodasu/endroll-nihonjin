# エンドロールの日本人

洋画のエンドロールに流れる日本人スタッフの名前を見つけてタップする、全10本立てのブラウザゲームです。

- 遊ぶ：https://jirodasu.github.io/endroll-nihonjin/
- iPhone：Safariで開いて「共有 → ホーム画面に追加」で、アプリのように遊べる（一度開けばオフラインでも可）
- 現在の版：`js/config.js` の `VERSION`（変更履歴は [CHANGELOG.md](CHANGELOG.md)）

## ファイルの地図

| ファイル | 中身 | こんなときに触る |
|---|---|---|
| `js/config.js` | 速度・人数・点数・本数などの数字 | 難易度や点数の調整 |
| `js/data.js` | 名前・ジャンル・役職・作品名の部品 | 名前やジャンルを増やす |
| `js/audio.js` | 効果音・BGM・映写機の音（すべて合成） | 音を変える |
| `js/game.js` | クレジット生成・判定・結果・シェア | ルールや画面の流れを変える |
| `css/style.css` | 見た目（色・書体・ジャンル別の館内） | デザインを変える |
| `index.html` | 画面の骨組み（タイトル・一時停止などの文言） | 文言を変える |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面追加・オフライン用 | 基本的に触らない |
| `docs/SPEC.md` | ゲーム仕様書 | 仕様を確認・説明するとき |
| `docs/SOUND.md` | サウンド仕様書 | 音を相談するとき |
| `AGENTS.md` | AIに作業を頼むときの引き継ぎ書 | 別のAIに渡すとき |

ビルド作業は不要です。ファイルを直して `main` に入れれば、数分でGitHub Pagesに反映されます。

## 更新のしかた（GitHubの画面だけでできる）

1. 直したいファイルを開いて、鉛筆アイコンで編集する
2. `js/config.js` の `VERSION` を上げる（例：`1.0.0` → `1.0.1`）。遊ぶ人の端末に新しい版が届く合図になる
3. `CHANGELOG.md` の一番上に、新しい版の変更点を書き足す
4. 「Commit changes」で `main` に入れる

## 別のAIに作業を頼むとき

- リポジトリを渡せるAIなら「`AGENTS.md` を読んでから作業して」と頼む
- ファイルを貼り付けるAIなら、`AGENTS.md` と、触りたい場所のファイル（表の右列を参照）だけを渡せば足りる
