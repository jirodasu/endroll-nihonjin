# ゲーム仕様書（ver 1.0.0 時点）

数値はすべて `js/config.js` の `CONFIG` が正本。ここに書いた数値は、その時点の値を書き写したもの。

## 遊び方
- 1本の作品のエンドロールが、画面の下から上へ流れる
- 日本人の名前（ローマ字、名→姓の順。例：Kenta Morita）をタップすると正解
- 違う人をタップする、または日本人が画面の上へ抜けてしまう（見逃し）と、フィルムが1本減る
- フィルムは3本。0本になると「途中退場」で結果画面へ
- 全10本を観終わると「完走」で、評価付きの結果画面へ

## 1本ごとの変化（作品番号を r とする）
| 項目 | 式 | 第1作 → 第10作 |
|---|---|---|
| スクロール速度 | min(230, 62 + (r−1)×14) px/秒 | 62 → 188 |
| 日本人の人数 | min(6, 1 + floor(r×0.7)) | 1, 2, 3, 3, 4, 5, 5, 6, 6, 6 |
| 主要スタッフ欄 | 4 + r 枠（最大9） | 監督・脚本・製作…VFX監修 |
| 出演者 | ジャンル固有 2〜4人 ＋ 共通 4+r 人 | |
| 部署 | 2 + r 部署 ＋ ジャンル固有1部署 | |
| 名前がずらっと並ぶ欄 | 1 + floor(r/2) 欄、各 min(18, 6+2r) 人 | VFXのCompositorsなど |

- 日本人は、監督（先頭の枠）を除く全ての枠からランダムに選ぶ
- 全員見つけると、残りは5倍速で早送りになる

## 得点
- 発見1人：100 ＋ コンボ×25 ＋ 早見つけボーナス（画面の下の方で見つけるほど高く、最大100）
- コンボ：続けて見つけるほど増える。誤タップ・見逃しで0に戻る
- パーフェクト（その作品をノーミスで全員発見）：+300点、フィルムが1本戻る（最大3本）

## 評価（完走時、全作品の発見率で決める）
| 評価 | 発見率 | 称号 |
|---|---|---|
| S | 95%以上 | エンドロールの番人 |
| A | 80%以上 | 最後まで席を立たない人 |
| B | 60%以上 | 名前を探す観客 |
| C | それ未満 | 本編派の観客 |

途中退場のときは評価なし（「—」と「途中退場」を表示）。

## ジャンル（6種）
SF・ホラー・西部劇・ロマンス・アクション・ノワール。10本のうち最初の6本で全ジャンルを1回ずつ出し、残り4本はランダム。同じジャンルは2本続けない。

ジャンルで変わるもの：
- タイトルの書体と色、館内の背景色
- 作品名の部品、固有の配役、固有の部署（例：西部劇の Livestock、ホラーの Creature Effects）
- BGM（docs/SOUND.md）

## 画面
- **タイトル**：遊び方の説明と見本の3行。背景で見本のエンドロールがゆっくり流れる
- **上映中のHUD**：作品番号とジャンルと作品名、見つけた人数、得点、フィルム残数、コンボ、一時停止、消音
- **幕間**：作品名、パーフェクト表示、見つけた人と見逃した人（日本語の役職と漢字表記付き）、10本の上映記録、次の作品のジャンル
- **結果**：評価、上映記録、得点・本数・人数、シェア文（Xに投稿／コピー）、見つけた全員の一覧
- アプリを裏に回すと自動で一時停止する。PCでは Space / Esc でも一時停止できる

## 上映記録の色
金＝パーフェクト、橙＝ミスあり、灰＝ひとりも見つけられず。シェア文では 🟨🟧⬛ で表し、未上映は ⬜。

## シェア文の形
```
洋画のエンドロールで日本人の名前を探すゲーム『エンドロールの日本人』
全10本を完走、評価S「エンドロールの番人」
🟨🟨🟧🟨🟨🟨🟨🟨🟧🟨
見つけた日本人 38/41人・31,402点
いちばんの早見つけ：THE HOLLOW HOUSEのCaterer、Akira Kawaguchi（川口明）さん
https://jirodasu.github.io/endroll-nihonjin/
```

## 名前の作り方
- 日本人：名60個前後 × 姓60個前後のローマ字。漢字は代表的な書き方を1つ当てる（`KS`・`KG`）
- 西洋人：名60個 × 姓70個。22%の確率でミドルイニシャルが付く
- 同じ作品の中で同じ名前は出さない
