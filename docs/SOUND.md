# サウンド仕様書（ver 1.0.0 時点）

音は作者の指定で「ゲーム音楽業界30年のプロ。キャラクターや世界観を踏襲した音作りが得意で、常に最短技術と効率化を図る」という立場で作る。音声ファイルは使わず、すべて `js/audio.js` の WebAudio で合成する。

## 全体
- 音量：全体 0.7、BGM 0.32。効果音が埋もれないようにBGMを控えめにしている
- 音域：BGMは中低域、正解音は E5（約659Hz）より上に置いて、ぶつからないようにしている
- 「上映開始」のタップで音が鳴り始める（ブラウザの決まりで、タップ前は音を出せない）
- 消音ボタンは全体に効き、設定を `localStorage` に保存する
- iPhoneのマナーモード中は鳴らないことがある

## 効果音 `SE`
| 名前 | 場面 | 作り |
|---|---|---|
| `found(combo)` | 日本人を発見 | E5の三角波に、5度上のサイン波と倍音。コンボ1つごとに半音上がる（最大9半音） |
| `wrong()` | 違う人をタップ | 150→95Hzの矩形波（ローパス700Hz）に75Hzのサイン波 |
| `miss()` | 見逃し | B4→B3へ滑り落ちる三角波、0.55秒 |
| `clear(perfect)` | 作品の終わり | ド・ミ・ソのアルペジオ。パーフェクトのときは上のド・ミを足して5音 |
| `over()` | 途中退場 | ソ→ミ♭→ドのサイン波、0.28秒間隔 |
| `finale()` | 10本完走 | C→F→G→C の和音を、少しずらしてギターのように鳴らす |
| `tick()` | 消音を解除したとき | 短い「チッ」 |

## 映写機の環境音 `hum(on)`
ホワイトノイズを1500Hzのバンドパスに通し、24Hz（フィルムのコマ数）の矩形波で音量を揺らす。音量は0.0035、揺れの幅は0.002。上映中だけ鳴る。

## BGM `MUSIC`
- しくみ：25ミリ秒ごとに、先の0.12秒分の音を予約するステップシーケンサー
- 構成：8小節で1周。A（1〜4小節）は `play` だけ。B（5〜8小節）は `play` に `b` を重ねる。8小節目の最後の1拍に `fill` が入る
- 作品の開始で約0.4秒かけて音量を上げ、終了で約0.6秒かけて下げる。一時停止ですぐ止まり、再開するとループの頭から鳴る
- 早送り中もテンポは変えない
